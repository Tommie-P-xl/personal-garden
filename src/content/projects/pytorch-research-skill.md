## 项目简介

PyTorch Research Skill 为使用 AI 编程助手开展科研代码工作提供可按任务读取的规则。当前仓库 README 标注版本为 1.3.4，入口文件位于 `skills/pytorch-research-code-style/`。

## 覆盖任务

- 搭建 PyTorch 项目结构、配置、数据流程和训练评估代码。
- 编排多组实验，并在阶段间传递模型、特征等产物路径。
- 记录配置、日志和结构化指标，按需生成实验图表。
- 为已有代码提供中文注释、算法解释与 Tensor Shape 说明。
- 提供独立的 Skill 安装包维护与更新工具。

## 版本与安装

仓库采用分层结构，把 Agent 使用的 Skill 内容与仓库维护工具分开。安装方式、依赖要求和更新流程可能随版本调整，请查看[最新 README](https://github.com/Tommie-P-xl/pytorch_research_skill)及 [Releases](https://github.com/Tommie-P-xl/pytorch_research_skill/releases)。
